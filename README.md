## 📌 What Is This?

A high-performance, single-file launch landing page introducing **PetOlife's Unified Pet Identity Protocol** — the concept of giving every pet in India a permanent, verifiable digital identity that travels with them across vets, cities, and their entire lifetime.

## 🎨 Design Decisions

| Choice | Reason |
|--------|--------|
| Dark theme (`#0a0c0e` base) | Conveys trust, premium feel, medical-grade seriousness |
| Gold accent (`#e8c547`) | Warmth + authority — the "identity" colour |
| Playfair Display + DM Sans | Editorial credibility paired with clean readability |
| Custom cursor | Signals craft and polish from the first second |
| Floating Pet ID Card | Makes the abstract concept (digital identity) tangible and real |
| Scroll-reveal animations | Guides attention — reveals story progressively, never overwhelms |
| Zero dependencies | Founding-level code: portable, auditable, fast anywhere |

---

## 🔧 Technical Highlights

- **Single HTML file** — entire site in one portable artifact
- **Pure CSS animations** — no JS libraries needed for motion
- **IntersectionObserver API** — scroll-triggered reveals without scroll listeners
- **Custom cursor** with blend-mode difference effect
- **CSS Grid + Flexbox** — fully responsive layout
- **Google Fonts** — loaded via CDN, no local assets required
- **Interactive waitlist form** — email validation + confirmation state
